# SNG-415 — The drift audit, and what `basis` was worth

**Author:** Aevi (PO) · **Date:** 2026-08-10
**Prompted by:** my own flag in SNG-407 — *"three moved locations have authored local layouts whose
bearings are now different"* — which I raised and then did not act on for several passes.

---

## §1 — ⛔ FOUR OF EIGHT TOWNS DRIFTED. ONE PLACEMENT MOVED.

SNG-407 moved eleven locations. Re-measuring the eight authored local layouts against current terrain:

| town | authored river bearing | now | drift |
|---|---|---|---|
| **Echo River Crossing** | −124° | 168° | ⛔ **68°** |
| **Greyhearth** | 23° | −61° | ⛔ **84°** |
| **Kindlerow** | 0° | 92° | ⛔ **92°** |
| **The Figure-Works** | −124° | −37° | ⛔ **87°** |
| Millbrook | 156° | 156° | **0°** |

**Half the corpus had a badly stale measurement.** ⚠️ **And only ONE of 38 placements was actually wrong.**

---

## §2 — ⛔ WHY: `basis` TURNED A REWRITE INTO A FIVE-ROW AUDIT

Because every placement records **which gradient decided it**, the exposure was computable rather than
assumed:

| basis | n | exposed to the drift? |
|---|---|---|
| **`road`** | 14 | ⛔ **No — roads move WITH the town** |
| `prose` | 5 | No — the seed does not change |
| `tradition` | 3 | No |
| `between` | 3 | No |
| **`river` / `uphill`** | **5** | ⛔ **Yes** |

**Of those five, four were still correct** — the uphill bearings had not drifted, only the rivers had. ⛔
**One placement moved: `erc_fisher_shacks`, from −124° to 168°.** Its own reason was *"riverward and
UPSTREAM, where the contamination is worst"* — and when the town snapped onto real water, upstream stopped
being that way.

⚠️ **Without `basis` I would have faced a choice between re-deriving all 38 by hand and leaving all 38
suspect.** CCode asked for that field; I added it only because my first attempt to answer his threshold
question failed for want of it. **It has now paid for itself twice.**

---

## §3 — THE GENERAL SHAPE, BECAUSE IT KEEPS RECURRING

**A derived measurement stored beside authored content goes stale silently.** Same class as the place-name
signatures, the base-versus-live seam, the stale `HYDRO.json`, the pre-rebuild feature addresses.

⛔ **The fix that works is not "remember to re-measure" — it is recording WHAT EACH DECISION DEPENDED ON,
so staleness becomes a query instead of a re-read.** `basis` does that for layouts; the polar signature
does it for names; `toward` now does it for roads.

⚠️ **Everything in `_measured` is a CACHE and should be regenerated by the pipeline, not trusted from the
file.** It is in the corpus so the reasoning can be argued with, not so it can be read as truth.
